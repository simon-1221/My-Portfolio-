# Simon Portfolio 🚀

A modern, fully responsive, and interactive personal portfolio website built using **HTML, CSS, and JavaScript**.  
This portfolio showcases projects, skills, certificates, contact information, and GitHub repositories with a clean UI and smooth animations.

---

## 🌟 Features

- 🎨 Modern UI/UX Design
- 🌙 Dark / Light Mode Toggle
- 📱 Fully Responsive Design
- ⚡ Smooth Animations & Reveal Effects
- 📂 Dynamic Project Cards
- 🏆 Certificates & Rewards Section
- 🔍 Project Search & Sorting
- 📊 Skills Progress Bars
- 📬 Contact Form
- 🔝 Back-to-Top Button
- 📈 Visitor Counter
- ✨ Interactive Particle Background
- 🛠 Add / Edit / Delete Project Functionality
- 💻 Compiler Modal for Running Projects Online

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome Icons
- Google Fonts
